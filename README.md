🧮 Calculadora GUI com Python e Tkinter
Este projeto é uma calculadora com interface gráfica desenvolvida em Python usando a biblioteca Tkinter.
Ela permite realizar operações básicas (adição, subtração, multiplicação e divisão) com botões clicáveis e também aceita comandos via teclado, como:

Números (0-9)

Operadores (+, -, *, /, .)

Enter para calcular

Backspace para limpar

💻 Requisitos:
Python 3.x instalado

Tkinter (geralmente já incluído no Python)
